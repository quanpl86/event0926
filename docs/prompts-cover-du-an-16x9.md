# Prompt cover dự án — Gợi ý cho bạn

File này đủ **64 prompt** cho 16 màn × 4 card. Mỗi học sinh chỉ thấy 4 card, tùy nhóm lớp và sở thích đầu tiên.

| Thông số | Giá trị |
|---|---|
| Tỉ lệ | **16:9** |
| Pixel xuất | **1920×1080** (không xuất 1:1) |
| Định dạng | PNG hoặc JPG, cạnh dài 1920 |
| Safe zone | Mặt + sản phẩm nằm giữa khung, cách mép trên/dưới ≥ 18% |
| Cấm trên ảnh | Chữ poster, logo TEKY, số điện thoại, watermark, headline |
| Card trên web | Title / mô tả / chip đã có sẵn — cover chỉ là cảnh |

Tên file gợi ý: `cover-{nhom}-{so-thich}-{id}.png`

- Nhóm: `g12` lớp 1–2 · `g35` lớp 3–5 · `g67` lớp 6–7 · `g89` lớp 8–9
- Sở thích: `robot` · `game` · `design` · `digital-world`

---

## Style lock (dán vào mọi prompt nếu tool yêu cầu style riêng)

```text
TEKY Vietnamese STEM workshop campaign style: bright mint and off-white studio background, soft teal color blobs, tiny plus signs and rings, photoreal mixed with light graphic UI cards floating around the scene (white/mint rounded frames, soft shadow). Clean commercial daylight from the left, warm smile, teal or green outfit. High detail, print-sharp, 16:9 landscape 1920x1080. No poster headline, no logo, no phone number, no extra typography.
```
